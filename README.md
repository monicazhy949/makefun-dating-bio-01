## The bio

> Looking for someone brave enough to date me: I remember everything you've ever typed — including the drafts. Especially the drafts.

## How it works

`main.py` writes the single-line bio (131 characters) to `/output/entry.txt`.
No network, no secrets, no dependencies — just the standard library.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
